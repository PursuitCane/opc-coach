- 避免和赞助商抢蛋糕，突出能合作的部分

- 场景收敛在泛科技：这类opc普遍“技术/产品能力强，但商业、增长、融资训练不足”，AI Coach的价值更集中；同时我们有泛科技领域创业者、投资人的成熟方法论

- 产品逻辑：用经典创业方法论主动发现商业盲区，用长期决策记录陪创业者持续验证，并最终通过真实的“决策—行动—结果”数据形成壁垒

- **问题：**

    - opc有产品/技术/想法，但**缺乏系统商业框架，不知道自己的商业逻辑哪里没想清楚**

    - 产品、增长、用户、定价、融资等事情同时发生，无法持续判断 **“当前最重要问题有哪些、下一步最该做什么”**，导致精力分散

    - 创业决策分散在聊天、文档和印象中，**缺乏持续记录、复盘和行动验证闭环，历史经验难以复用**

- **解决方案：**

    - **商业思路诊断**：上传材料、项目介绍，拆解用户、需求、商业模式、渠道、竞争等关键模块，并给出下一步建议

    - **AI Coach 主动追问**：用苏格拉底式提问 \+ 创业方法论帮助用户补全逻辑，引导深入思考

    - **持续陪跑与复盘**：记录每一次决策点、行动和结果，持续给出下一步验证建议

    - 财务指标：付费转化率、客单价、毛利、CAC

### 解决方案（理清 → 聚焦 → 复盘）

#### 创业coach: 帮你理清商业思路，优化商业计划~~书~~，成为创业者的陪跑coach

- 用经典创业方法论梳理商业思路并形成完善的商业计划，并且真实地为OPC提供行动计划，持续陪跑（每日复盘，挑战关键假设，后续资源链接）

- 目标用户：泛科技 OPC

#### 核心功能

##### ① 帮你“看明白”——专家视角的商业诊断

通过产品理论、创业方法论，形成投资人/专家视角

##### ② 帮你“想清楚”——苏格拉底式商业推演

##### ③ 帮你“持续做对”——长期陪跑、决策记忆与复盘

系统性记录公司的：问题 → 假设 → 决策 → 行动 → 结果 → 新认知

#### 产品特性\-不同于通用AI

- **有立场，主动 challenge**

    不盲目认同，不做情绪价值型附和

    根据经典商业框架，主动指出逻辑漏洞、关键假设和盲区

- **区别于一次性问答，记得你为什么做过这些决定**

长期Memory：持续记录问题、假设、决策、行动和结果，让每次新判断都建立在过去真实结果上，而不是重新从零开始

#### 数据飞轮

沉淀「假设—决策—行动—结果」真实数据资产，形成数据飞轮壁垒

#### 生态构建

##### 资源链接与平台化：从“给建议”走向“帮你找到下一步资源”

Coach 不只告诉你“应该融资”，而是判断你现在是否该融资、缺什么证据，并把合适的投资人/资源带到下一步：

缺资金 → 匹配投资人、基金、孵化器、融资活动

缺证据 → 匹配行业研究、市场数据、专家观点、Proof / Insight 能力

缺客户/渠道 → 匹配展会、产业伙伴、渠道资源、潜在客户

缺政策支持 → 匹配政府补贴、产业园、创业扶持政策、申报机会

缺技术能力 → 匹配模型、Token、开发平台、技术服务商

缺专家判断 → 调用专家 Skill 或真人咨询

##### 专家 Skill Marketplace：把人的经验产品化

不同专家共创，把方法论封装成可调用的 Skills：

- VC：融资准备度诊断 Skill

- 产品专家：PMF 诊断 Skill

- 增长专家：Growth Diagnosis Skill

- SaaS 专家：定价与 Unit Economics Skill

- 品牌专家：Positioning Skill

- 法务：创业合规 Skill

- 政策专家：补贴/政策匹配 Skill

#### 技术亮点

长期memory、苏格拉底式提问、harness自进化商业coach
