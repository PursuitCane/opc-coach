# BP 总结 · 起名结论

> 本文件是 `raw.md`（BP 大纲源稿）的浓缩总结 + 产品命名结论，供路演准备与对齐使用。
> 配套文档：`raw.md`（源稿）、`tech-highlights.md`（技术亮点）。
> Tag: `#shenicest-fission`

## 一句话定位

面向泛科技 OPC 的 AI 创业合伙人 / Business Coach：
用经典创业方法论主动发现商业盲区，用长期决策记录陪创业者持续验证，最终靠真实的「决策—行动—结果」数据形成壁垒。

## 起名结论

**产品名：军师（OPC 军师）。**

理由：
- 承接现有代号 `opc-sage`，谋士感强——陪你打仗、给策略。
- 同时装得下"诊断 + 追问 + 陪跑"三件事。
- 暗含"有立场、会 challenge"的性格，比 Copilot / Cofounder AI 这类中性词更有记忆点。

备选（如需更直白或更工具化）：合伙人 Copilot / Cofounder AI（直白但通用）、罗盘 Compass（强调判断下一步该做什么，偏工具感）。

## 内容总结

产品是一个 AI 创业合伙人，不是"BP 打分器"。核心价值：陪你把一个生意想明白、做出来，并记住整个过程；让每次新决策都建立在过去的判断、实验和结果之上。

- 客户：早期泛科技 OPC（Idea/Demo 走向商业验证）→ 后续 2-10 人早期团队 → 创业公司。
- 问题：缺系统商业框架、不知下一步最该做什么、决策散落无法复用。
- 解决方案：商业思路诊断（理清）→ 苏格拉底式追问（想清楚）→ 持续陪跑复盘（做对）。
- 壁垒：短期靠方法论 + 诊断流程；长期靠长期 Memory +「假设—决策—行动—结果」真实数据资产 + 自进化决策模型。
- 北极星：每日完成 ≥1 个有效商业决策闭环的 Founder 数。
- 商业模式：单次诊断付费 → 订阅 → 专家咨询/资源对接；B2B2C 卖给孵化器/创业营/VC。
- 生态：资源 mapping（缺钱/证据/客户/政策/技术/专家 → 对接资源）+ 专家 Skill Marketplace。

## 商业 Coach 反馈（评审视角的硬问题）

**1. 北极星漂亮，但"有效决策闭环"怎么判定？**
"每日 ≥1 个有效闭环"靠谁判定？若靠 OPC 自己回填结果，那结果回填率就是整个飞轮的命门，也是最难的一环——创业者做完决策往往不回来填结果（忙、忘、或结果难看），那"真实数据资产"就是空的，长期壁垒不成立。这是评委必戳的点，BP 里要给出让人回填的机制，而不只是列成一个一级指标。

**2. "主动 challenge" 是卖点，也是留存杀手。**
被 AI 反复质疑反人性，尤其创业者本就焦虑。真投资人能 challenge 是因手里有钱/资源，我们 challenge 的筹码是什么？需要"张弛机制"——何时质疑、何时给正反馈，否则用户被怼两次就走。

**3. 生态 / Skill Marketplace 是第二曲线，别当第一曲线讲。**
双边网络冷启动极难，前提是先有足够多活跃 Founder。路演主体讲"单个 Founder 把生意想明白"这条已验证价值，生态作为愿景一笔带过，否则显得"还没证明单机价值就想做平台"。

**4. 收入阶段 1（单次诊断付费）与长期壁垒（陪跑数据）矛盾。**
单次诊断=一次性交易，用完就走，不沉淀决策数据；而壁垒恰恰靠持续陪跑数据。要想清楚：诊断是不是只是获客钩子（免费/低价），真正要收的是订阅陪跑？

**5. 与赞助商边界。**
资源 mapping 里"缺技术 → 匹配模型/Token/开发平台"很可能踩赞助商业务。包装成"把流量导给生态伙伴"，而非"我们自己也做"。

## 一句话总结

天花板高、故事完整，最强的是"决策记忆 + 数据飞轮"。阿喀琉斯之踵是结果回填率——飞轮转不转全看它。评委第一个问题大概率是："凭什么让忙到飞起的创业者，每天回来告诉你上个决策的结果？" 建议把这个问题的答案做成 BP 的亮点，而不是待解风险。
